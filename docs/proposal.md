# Moon FindCore 项目申报书

项目负责人账号：btlqql。项目方向：基础组件与信息检索。
GitHub：https://github.com/btlqql/moon-findcore公开仓库，拟用 `btlqql/moon-findcore`。
当前阶段：选题与架构规划；本文按立项阶段表述功能、交付和验收目标。

## 项目简介与通用价值

提供可嵌入 MoonBit 应用的持久化全文检索库，并通过 CLI 搜索真实文档。项目采用 MoonBit 实现核心处理能力，提供可复用库接口与命令行入口，使使用者能够把同一能力嵌入应用、离线处理或 CI 流程。适用范围通过不同用途的完整示例说明，并以输入、判断过程和可核验输出体现实际价值。

## 核心功能

文本分析；倒排表；BM25；布尔与短语查询解析；字段筛选；增量更新删除；版本化索引存取；命中片段与 CLI。英文词法和中文字符双字切分的行为分别声明；不宣称自然语言理解或完备中文分词。

## 三个完整使用场景

1. 软件文档检索：输入开源项目的安装、API 与排错文档，建立带标题和正文的索引；按关键词、短语和字段检索，输出排序、命中片段与原文路径，帮助使用者定位操作方法。

2. 工单问题检索：输入公开且可再分发的工单文本，保留标签、状态和正文；结合字段筛选与排序查询相似问题，输出候选工单与匹配位置，供维护者判断是否已有解决方案。

3. 知识库更新：输入混合中英文知识条目，演示新增、修改和删除后的增量索引；输出更新后的查询结果及高亮，使应用能够复用检索能力，同时明确中文字符切分的能力边界。

## 技术路线与工程实现

将文档分析结果写入带位置的倒排表，查询解析得到表达式树，再执行筛选、交集与评分；持久化格式包含版本与完整性信息。核心逻辑采用有类型的数据结构、明确错误结果和可测试执行步骤；文件、网络或进程适配与核心处理分层。实现过程中用小规模确定性输入建立正确性基准，再使用真实场景和规模数据检查可用性。对外暴露稳定接口，避免把演示脚本作为唯一使用方式。

## 预计交付与验收方式

交付目标包括公开 MoonBit 源码、库接口、CLI、三个完整场景及输入来源、单元与集成测试、适用目标的 CI、安装使用说明、设计与边界文档、源码统计及独立安装验证记录。有效生产 MoonBit 源码内部估算为 5,000–8,000 行，测试、示例、生成语料和辅助脚本分别统计，该估算不作为官方验收门槛。

一万文档记录索引体积、构建耗时与查询分位耗时；BM25 数值、布尔结果和短语位置使用独立计算核验；保存重载结果一致。失败验证覆盖畸形查询、文档更新/删除、损坏索引、Unicode 边界。十月为单机检索库，不做向量数据库或分布式搜索。

## 原创性、来源与开源计划

拟原创实现本项目的数据模型、处理流程和业务判断，不把九月项目旧代码或简单拆分计入此次新成果。[Xapian BM25 算法说明](https://xapian.org/docs/bm25.html)作为设计或标准参考，当前没有声明已复制该项目代码。计划采用 Apache-2.0；实际采用的依赖、参考实现和数据集逐项记录版本、链接、许可证与使用范围。生态查重仍须补齐同类项目的接口、能力和差异证据，不能声称已证明唯一性。

## 制作安排与技术取舍

本项目属于第 3 轮：先完成模型与接口，再交付可运行的核心链路和三个场景，随后完成规模验证、失败路径、当前提交的 CI 与公开包独立消费验证。主要取舍是让统一核心能力服务多个场景，同时将运行环境和暂不支持的语义写清；完成状态以实际源码和验证记录更新。目标截止日期为 2026-10-31，进度以实际里程碑为准。
