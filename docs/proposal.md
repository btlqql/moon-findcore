## 一、项目简介

FindCore 为具有 ID、文本字段与可选元数据的文档建立位置倒排索引，提供 BM25 排序、布尔查询、短语查询、字段限定及高亮范围。当前修订增加精确元数据筛选、分页和全匹配结果分面，使使用者可以把文本相关性与文档分类、租户或版本标签等筛选条件结合。

## 二、使用问题与组件职责

文档检索往往不仅需要找出包含关键词的记录，还需要限定分类、保持翻页顺序，并知道全部匹配结果中各分类有多少条。FindCore 将文本匹配、元数据筛选和分面统计放入同一请求链路，适用于本地知识资料、产品目录和文档集合检索。它提供检索能力，不充当调用方的身份鉴权或租户安全边界。

## 三、核心机制与实现

### 索引与查询

索引记录每字段词项、文档内位置及长度，支持词项和短语查找、AND/OR/NOT、括号及字段限定。分析器对拉丁词做小写归一，对 CJK 使用单字词项，不声明具备词典分词。文档按 ID 执行 upsert 或 delete；快照存储版本标识、字段和原始文档，重新加载时重建派生索引。

本次增加查询文本与 token 数量上限，拒绝非整数 limit 和 offset；索引更新前校验原始文档，避免删除动作掩盖重复 ID。字段限定查询的高亮只标记所指定字段，防止把同词项在无关字段中的出现也标成命中。

### 筛选与分页

where 是元数据字段的精确相等条件，多个条件取交集；字段缺失不匹配，显式 null 与字段缺失区分。元数据存在且非 null 时必须是对象。先计算文本匹配和 BM25 分数，再按元数据过滤；当前 BM25 的词频统计仍基于整个索引语料，未按过滤后的子集重新计算。

过滤后的结果按分数降序排序，并以稳定 ID 比较处理严格同分。offset 与 limit 只决定返回片段，不改变 total。该稳定 ID 比较沿用 MoonBit 的默认字符串比较，不承诺自然语言排序；这也不是允许并发更新时的游标分页。

### 分面统计

facets 指定需要统计的元数据字段。统计范围是当前查询及筛选后、分页前的全部匹配文档。每个分面返回 buckets 与 missing：显式 null 可以形成桶，字段缺失单列计数。桶按数量降序，数量相同时按规范值的显式词法顺序排序。本次独立检查发现了默认字符串比较与该要求的差异，已改为 lexical_compare 并加入回归断言。

数组或对象元数据作为一个完整值参与分面，不展开成多个标签；空页仍保留完整 total 和分面。

## 四、完整案例

### 案例一：租户筛选与分类分面

五份都包含 moon 的文档中，四份带 tenant=x，一份 tenant=y。对 x 筛选后，total=4；offset=1、limit=1 时只返回第二份匹配文档，但 kind 分面仍统计全部四份：guide 两份、显式 null 一份、缺失字段一份。调用方能够分别说明当前页、全部匹配量和分类分布。

### 案例二：空值、缺失与空页

where 指定 kind=null 时，仅返回显式保存 null 的文档，缺少 kind 的文档不被混入。offset 超过匹配数时 hits 为空，但 total 和分面保留。分面并列桶的顺序用固定断言检查，避免依赖 Map 遍历顺序。

### 案例三：索引更新与恢复

执行删除和更新后，旧词项不再参与匹配，新文本可以被检索。快照重新加载后，在相同元数据条件、分页参数及分面字段下得到相同查询结果。原始输入已有重复 ID 时，即使后续动作尝试删除该 ID，也会先被校验拒绝。

## 五、工程结构与可复核验证

领域计算位于 MoonBit 核心，标准 JSON 通过 execute 转换为语义值并调用 run。cmd/main 提供 JS CLI；核心可面向 JS、wasm、wasm-gc、native 测试，宿主脚本单独承担文件读取与参考核对。数据来自合成固定样本和确定性随机数据，没有声明真实生产用户或商业部署。

当前包含 16 项 MoonBit 测试，以及通过真实 Node CLI 执行的 12 组 JSON 夹具。独立 Python 公式检查 30 份文档的 BM25 分数及快照恢复；新增 20 组随机语料，使用 Counter 验证筛选、分页、分面、空值和缺失字段，并检查快照重载结果一致。 新案例输入见 examples/scenario-4.json；完整断言位于 tests/cases.json 和新增回归测试文件。

复核命令：

```sh
moon update
moon test --target js
moon test --target wasm
moon test --target wasm-gc
moon test --target native
moon build --target js
node scripts/check.mjs
python -B scripts/reference.py
moon run cmd/main --target js -- examples/scenario-4.json
```

native 需要 C 编译器；实际执行后端、结果及对应版本以交付核对记录和公开 CI 为准，不能将“提供测试命令”当成“测试已经通过”。

## 七、来源、复用与当前边界

领域实现和本次新增机制随仓库开源。MoonBit 标准库、Node 内置模块及 Python 标准库分别用于运行、宿主操作或独立核对；来源说明见 THIRD_PARTY.md。共享 JSON/CLI 脚手架按基础设施说明，不将其当成不同项目各自独有的领域创新。

当前索引和查询均在内存中完成，快照载入会重建索引，没有磁盘倒排数据库、模糊搜索、通配符、词干化或语义向量检索。高亮输出 Unicode 码点范围，不是 HTML 或完整短语跨度。元数据筛选不替代鉴权；分面是完整值统计，不展开多值字段。不同分数在序列化显示时可能因浮点舍入看起来相同。

本稿撤去旧参考方案中尚未完成的高级能力、生产规模和性能目标。当前功能、测试与开发记录可以实际复核；项目仍是持续完善的组件，不能把原先 4,000–8,000 行内部目标写成已经交付的代码量。
